# Handoff

Everything needed to continue building Clavis in Claude Code, a local editor, or anywhere else. Architecture is in `06-app-architecture.md`; this file is the operational layer — where things are, how to build, what to run, and what is known to be broken or pending.

Current shipped version: **v0.10** ("quiet surfaces" — low-contrast re-theme + cloze-leak fix).

---

## 1. Files

```
pipeline/
  extract.py        SVG → scenes with per-language balloon geometry
  annotate.py       tokenise, lemmatise, filter, attach frequency
  etym.py           EtymDB 2.1 → origins + cognate/borrowing edges
  pseudo.py         pseudoword foils for baseline tests — NOTE: ships in clavis-pipeline.zip,
                    not in pipeline/; pseudo.json is cached so it is not regenerated by the
                    commands below. Recover it from the zip if the corpus ever changes.
  pack.py           final assembly → clavis.html
  scenes.json  lexicon.json  etym.json  pseudo.json      cached intermediates

app/
  template.html          THE SOURCE OF TRUTH (2,368 lines) — all logic, CSS, markup
  vendor-g6.min.js       AntV G6 v5.1.1 UMD, 1,383,347 bytes (npm pack @antv/g6)
  clavis.html            BUILD OUTPUT (~11,077 KB) — the deliverable
  clavis-standalone.html clavis.html wrapped in doctype/head for direct opening

corpus/                  raw Pepper&Carrot pages + per-episode translator SVGs (ep01–ep23)
research/                the seven research memos
docs/                    this documentation set
clavis-pipeline.zip      the open-source generator bundle for distribution
```

**`template.html` is the only file to edit for app changes.** `clavis.html` is generated and should never be hand-edited — the next `pack.py` run overwrites it.

Placeholders `pack.py` fills: `__DATA_B64__`, `__IMAGES__`, `__SIZES__`, `__G6_JS__`.

## 3. Testing

**Playwright lives on a non-default module path.** This is the single most common thing to get wrong:

```bash
NODE_PATH=/home/claude/.npm-global/lib/node_modules node /tmp/<script>.js
```

`require('playwright')` and `chromium.launch({})` then work with no `executablePath`.

Rebuild the preview wrapper before every run:

```python
h = open('/home/claude/app/clavis.html', encoding='utf-8').read()
open('/tmp/clavis-preview.html','w', encoding='utf-8').write(
  '<!doctype html><html><head><meta charset="utf-8">'
  '<meta name="viewport" content="width=device-width,initial-scale=1"></head>'
  '<body style="margin:0">' + h + '</body></html>')
```

| Script | What it covers | When to run |
|---|---|---|
| `clavis-boot-test.js` | Fresh install → real onboarding clicks → all five views → full session; second context replays a v0.2→v2 localStorage migration | **Every publish** |
| `v8b.js` | G6 suite: node/edge counts, fisheye place+drag, relations lens, families, search → card → web handoff, Paths branch tap → walk, touch tool sizing ≥44 px | Any Cosmos/Paths change |
| `v9.js` | Page lettering counts (ja/es), encounter lettering + halo, gloss on tap | Any balloon/scene change |
| `v9t.js` | Pixel 5 touch context: balloon tap → caption highlight, touch gloss, tap-target sizes | Any touch-surface change |
| `v9f.js` | Deterministic-clock frame sampling of the morph | Any transition change |
| `v10.js` | Light/dark screenshots of every view **+ the cloze-leak regression** | **Every publish** |

These live in `/tmp/` and are scratch — recreate them from the descriptions here if the container is reclaimed. The two that matter most are `clavis-boot-test.js` and `v10.js`.

### The deterministic-clock technique

Stub `performance.now` and `requestAnimationFrame` to read a fake `window.__clock` you advance yourself, then assert on specific frames. Wall-clock waits cannot reliably sample the middle of a 520 ms animation. This is what surfaced the unclamped-interpolation bug in the morph — jump the fake clock backwards and the shape inverts, then `createRadialGradient` throws *"r0 provided is less than 0."* Fixed with `clamp(t, 0, 1)` plus a radius floor, and the bug is reachable in real use when a backgrounded tab resumes.

### The cloze-leak regression

The single most important check. `v10.js` seeds a due Spanish card with credible geometry, forces a cloze encounter, inspects the rendered `.btext` for the answer word, asserts no leak, clicks an answer, and confirms the gap is gone afterwards. Expected output: `LEAK: false`, then `balloon has gap: false`.

It exists because an earlier build wired the mask only into the "See the whole page" path and not into the default cropped view — so the very first thing a cloze showed was the answer to the question below it. Re-run it for **any** change touching balloons, masking, or scene rendering.

## 5. Gotchas that will cost an hour each

| Symptom | Cause | Fix |
|---|---|---|
| Fisheye/relations lens shows no labels | G6's `auto-adapt-label` behaviour overrides the lens's own `nodeStyle` | `graph.updateBehavior({key:'adapt', enable: S.cosmos.exlens==='off'})` |
| BubbleSets contour missing on first paint | The plugin listens for `AFTER_RENDER`, which `setPlugins` doesn't fire | `graph.draw().then(()=>{ if(S.cosmos.exsets && G6.GraphEvent) graph.emit(G6.GraphEvent.AFTER_RENDER, {}); })` |
| `h.canUndo is not a function` | History plugin API not always present | Guard: `h && h.canUndo && h.canUndo()`, wrapped in try/catch |
| Morph shape inverts / gradient throws | Unclamped interpolation `t` after a backwards clock jump | `clamp(t, 0, 1)` and `Math.max(0.01, r)` on gradient radii |
| Japanese/Chinese text shows mid-word spaces | Translators' SVGs break CJK lines with literal spaces | Route through `lineOf(lang, str)` — display, gloss **and** TTS |
| Story mode opens on a title card | Episodes with near-zero alignment in the chosen language | `epCount` filter (≥6 scenes) before offering an episode |
| Cloze answer visible in the balloon | Mask not passed to the *cropped* renderer | Compute `maskNow()` once, pass to both; `''` means omit lettering entirely |
| Playwright "module not found" | Wrong global module dir | `NODE_PATH=/home/claude/.npm-global/lib/node_modules` |

## 6. Conventions to keep

- **Per-language geometry, always.** Use `rectFor(sc, lang)` + `rectOK(r)`, never the shared rect directly — that is `sc.r` in the packed data (`rect` is only the pipeline-JSON field name). The `q` field is what raised usable geometry to 90%.
- **CJK text goes through `lineOf`** before display or speech.
- **G6 colours come from `cssVar()`**, never hardcoded hex, or dark mode breaks.
- **Every on-screen claim gets a `cite(n)`.** The colophon is a requirement, not decoration.
- **Canvas animations return a stop function** and register it (`orbStop`, `cosmosStop`) so `render()` can tear them down.
- **Never invent an etymology.** If EtymDB is silent, show nothing (`07-etymology.md` §8).

## 7. Open work

Ordered by value, drawn from the rest of this doc set.

**Data and correctness**
1. **Migrate etymology to wiktextract / kaikki.org** — recommended by the research, permissively licensed, far richer where EtymDB is thinnest. `07-etymology.md` §7.
2. **Fix Chinese lemma matching** — 0.6% coverage is almost certainly a keying problem, and it blocks the most interesting CJK claim.
3. **Arabic root extraction** — needed before Arabic can serve as the control condition the design assigned it.
4. **Korean and Arabic balloon geometry** sit at 81–82% against 90% elsewhere. Because `rectFor` falls back to the shared rect only when a per-language box is *absent* — not when it fails `rectOK` — that gap shows up as roughly one balloon in five going unlettered in those two languages. Improving the per-script width metric is the fix. (Korean and Arabic also carry the line in far fewer scenes to begin with: 329 and 177 of 649.)
5. **Verify Pepper&Carrot's licence** independently — it is undocumented in the research corpus and the whole build rests on it.

**Instrumentation — the hypotheses are not currently measurable**

7. Surface origin-surfaced vs never-surfaced stability (tests H4′).
8. Surface branch-prediction accuracy: did taking a "*n* more bubbles become readable" branch actually make *n* scenes readable? (tests H8).
9. **FSRS parameter optimisation** on the user's own review log — the defaults are population priors, and an N=1 instrument should fit its own.

## 8. Open questions for the builder

Carried forward, unanswered:

1. **Does the light-mode Field view have enough presence at rest?** The specks were left at full saturation while only the frame was quieted. If it wants to be hazier, that is one knob — reduce the `paint()` opacity/saturation rather than touching the ground.
2. **Veil tuning was not reviewed.** The final morph pass raised drop radius to `0.5` scale with `0.04` jitter and alpha stops `0.5 / 0.2`, after an earlier pass read as too faint against the new light backgrounds. That change shipped without a verdict on it.
3. **Should there be a forgiving streak after all?** The build has no streak at all, which is a *stronger* position than the evidence requires — memo 06 recommends forgiving streaks (freezes, earn-back, no penalty for one missed day) and backs them with the largest behavioural dataset in the corpus. This was a design choice, not an evidential one, and `03-evidence.md` §10 says so.
