## 2. Delivered since the last status (this pass, 2026-09-16)

- **Release pipeline could never have published on this account** — its inter-job artifact
  handoff (~630 MB) exceeds the Free-plan Actions storage quota that CI's own uploads had already
  exhausted. Rebuilt so every job uploads straight into a draft GitHub Release and CI keeps only
  the small APK (D-26). *Until this landed, pushing a tag would have failed; it is safe now.*
- **Desktop CJK/Hebrew fallback fonts were the Thin weight** (variable fonts at their default
  instance). Replaced with Regular; payload 37 → 23 MB; notices corrected (D-27).
- **Pronunciation audio source added** for the languages English Wiktionary does not cover (D-28).
- **Screenshot matrix extended to RTL and 2× font scale; automated semantics and touch-target
  audit** added to the desktop suite (D-29).
- **Usability pass**: 35 findings, 24 fixed in this pass, 10 open with reasons, 1 withdrawn
  (`USABILITY.md`, D-30). The fixed set includes one blocker (session scroll carrying over between
  encounters) and the data-safety gap (Reset/Import kept no copy; Enter confirmed the erase).

## 7. Risks worth stating plainly

- The method is one person's experiment (D-18); nothing in the app is validated pedagogy.
- Unsigned installers on all three desktop platforms and an unsigned APK until the maintainer's
  keys exist; a signed build cannot update over an unsigned one.
- macOS and Windows packaging had never run before this pass's dry run; a first real tag may still
  surface platform-specific issues — the workflow deletes its draft on failure, so a failed release
  never publishes half a set.
